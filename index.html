「Webコンテンツ作成」の成果

本テーマについて

このテーマでは、HTML,CSS,JavaScriptを用いてWebページの構造、見た目、インタラクティブな処理を記述する基本的な方法について学び、これらを組み合わせて Web ページを構成する方法を学びます。

プロジェクト課題について

本Webサイトは、大学の「Webコンテンツ作成」の授業において、HTML・CSS・JavaScriptというWeb制作の基礎となるプログラミング言語の技術を習得する目的で制作した「NHK番組表Webサイト」である。全6回の授業を通じて段階的に理解を深める学習体系となっており、前半の講義ではHTMLを用いたWebページの骨組み・構造定義と、CSSを活用したレイアウト調整や装飾デザインの基本手法を学んだ。後半の講義ではJavaScriptの学習へ移行し、ユーザーの操作を受け取るイベント処理や、画面要素を操作するDOM操作の技術を習得した。これにより、ユーザーの入力に応じてリアルタイムで画面表示を動的に変化させる高度な技術を身につけることができた。その集大成として開発した本サイトは、画面上の検索フォームで希望のチャンネルやジャンルを選択して検索を実行すると、外部のNHK番組表APIへリクエストを送信し、取得した最新の番組データを画面上に自動で展開・表示する仕組みを備えている。しかし、開発の途中で「検索を実行するとプログラムが突然停止し、エラーが発生する」という課題に直面した。そこでブラウザのデベロッパーツールを活用してソースコードと通信内容を細かく分析・追究したところ、選択したチャンネルや条件によってAPIから返却されるデータの構造が異なり、プログラムが存在しないデータプロパティへアクセスしようとしていたことが原因だと判明した。この問題に対し、データを参照する前に該当データが正しく存在するかを検証する安全な条件分岐処理（NULLチェック等）をプログラム内に組み込み、不測のエラーを未然に防ぐ堅牢な対策を講じた。さらに、取得した番組タイトル、放送時間、出演者情報などの多岐にわたるデータをユーザーが見やすく整理された形で閲覧できるよう工夫した。JavaScriptの機能を駆使してulやliといったDOM要素を動的に生成し、CSSで定義した適切なレイアウト構造へ順次追加・描画する処理を実装した。ローカル環境での入念な動作確認と修正を重ねた後、最終的にGitHub Pagesを活用してWeb上へ一般公開することに成功した。一連の開発プロセスを通じて、エラーが発生しても論理的な思考で原因を特定・解決する重要性を学ぶとともに、各言語を連携させて実用的なWebサービスを形にするプログラミングの面白さと大きな達成感を得ることができた。

数当てゲーム

1~10までの間でランダムで設定される数字を当てるゲーム。プレイヤーがテキストボックスに数字を入れて回答のボタンを押すと答えの判定ができる。答えが間違っていたら入力した数が答えより大きいか小さいかを伝える。答えがあっていたら正解と表示する。３回間違えるか正解済みだった場合答えとともに終わっていることを伝える。

数当てゲームのページ: kazuate.html

各授業会の学習事項

第１回 WWW と HTML

今回学んだことは、WWWについてのこと、またWebページに使われているHTML文書の構成や要素、デバックについてだった。HTMLについては見出しを作ったり、ハイパーリンクを作ったり、画像を挿入したりと様々なことを学んだ。

演習の成果: 演習1-4: HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

今回学んだことはCSSによるWebページの装飾についてだった。CSSを使うことで前回のHTMLだけではできなかった強調表示やフォントを変えたりなど、Webページにいろいろな装飾ができるようになった。

演習の成果: 演習2-3: ウェブブラウザ説明ページの装飾

第3回 JavaScript の基本

ここまでで学んだことはWebコンテンツを作るための基礎部分である、HTML,CSS,JavaScriptの基礎を学んだ。JavaScriptはまだコンソールに文章を表示するだけのことしかできないが、webの文章や、背景などの見栄えはある程度整えられるようになった。

演習の成果: 演習3-6: オブジェクトの参照

第4回 DOM と JavaScript

ここまでで学んだことは、JavaScriptとHTMLで文字を入力できるボックスから、文字や数値を読み取り、読み取った結果を元に画面に出力する方法を学んだ。検索バーのようなものを作れるようになり、入力を受け付けられるようなプログラムを組めるようになったのでさらにwebデザインの幅が広がった。

演習の成果: 演習4-10: 足し算ページ

第5回 イベント処理

ここまでで学んだことはボタンを押すと何かを画面に映し出すJavaScriptのプログラム方法だった。ボタンを押すとすぐに画面に表示できるところまで来た。Webページとしての機能を作る最低限の力がついたと思う。

演習の成果: 演習5-7: DOMプログラミング(2)
