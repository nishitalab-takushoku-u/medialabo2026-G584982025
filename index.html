数当てゲーム

1~10までの間でランダムで設定される数字を当てるゲーム。プレイヤーがテキストボックスに数字を入れて回答のボタンを押すと答えの判定ができる。答えが間違っていたら入力した数が答えより大きいか小さいかを伝える。答えがあっていたら正解と表示する。３回間違えるか正解済みだった場合答えとともに終わっていることを伝える。

数当てゲームのページ: kazuate.html

各授業会の学習事項

第１回 WWW と HTML

今回学んだことは、WWWについてのこと、またWebページに使われているHTML文書の構成や要素、デバックについてだった。HTMLについては見出しを作ったり、ハイパーリンクを作ったり、画像を挿入したりと様々なことを学んだ。

演習の成果: 演習1-4: HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

今回学んだことはCSSによるWebページの装飾についてだった。CSSを使うことで前回のHTMLだけではできなかった強調表示やフォントを変えたりなど、Webページにいろいろな装飾ができるようになった。

演習の成果: 演習2-3: ウェブブラウザ説明ページの装飾

第3回 JavaScript の基本

ここまでで学んだことはWebコンテンツを作るための基礎部分である、HTML,CSS,JavaScriptの基礎を学んだ。JavaScriptはまだコンソールに文章を表示するだけのことしかできないが、webの文章や、背景などの見栄えはある程度整えられるようになった。

演習の成果: 演習3-6: オブジェクトの参照

第4回 DOM と JavaScript

ここまでで学んだことは、JavaScriptとHTMLで文字を入力できるボックスから、文字や数値を読み取り、読み取った結果を元に画面に出力する方法を学んだ。検索バーのようなものを作れるようになり、入力を受け付けられるようなプログラムを組めるようになったのでさらにwebデザインの幅が広がった。

演習の成果: 演習4-10: 足し算ページ

第5回 イベント処理

ここまでで学んだことはボタンを押すと何かを画面に映し出すJavaScriptのプログラム方法だった。ボタンを押すとすぐに画面に表示できるところまで来た。
