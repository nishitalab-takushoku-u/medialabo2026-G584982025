「Webコンテンツ作成」の成果

本テーマについて

このテーマでは、HTML,CSS,JavaScriptを用いてWebページの構造、見た目、インタラクティブな処理を記述する基本的な方法について学び、これらを組み合わせて Web ページを構成する方法を学びます。

プロジェクト課題について

今回の課題で作成したWebサイトは、Webサイトを作るための基礎的なプログラミング言語（HTML・CSS・JavaScript）を学ぶために制作した「NHK番組表Webサイト」である。 この授業は全6回で、段階的にステップアップしながら学べるカリキュラムになっている。前半の授業では、文字や図形を配置してページの「骨組み」を作るHTMLと、色や配置を整えてデザインをきれいにするCSSの基本を学んだ。 後半の授業では、ページに動きをつけるJavaScriptの学習に進んだ。ボタンが押されたときなどの「ユーザーの操作」を受け取る仕組みや、画面上の文字やデザインを書き換える技術を学んだことで、操作に合わせて画面がリアルタイムに変化する仕組みを作れるようになった。 その集大成として制作したのが、この「NHK番組表Webサイト」だ。画面にある検索フォームから、見たいチャンネルやジャンルを選んで検索ボタンを押すと、インターネットを通じてNHKが公開している最新の番組データを取りに行き、その結果を自動で画面に並べて表示する仕組みになっているのが理想だった。 しかし、完成までの道のりは簡単ではなく、第５回までの授業において、自分で組んだプログラムを確認してみると、結果を自動で持ってくる以前に、全ての文章を手打ちして文字を無理やり表示している状態だったのである。そのため、プログラムをほとんど最初から資料を見ながらながらにも組み直すこととなった。 この授業のJavaScriptの学習を最後のところで復習できたので良くなかったとは思わないが、どんなことでも確認を怠らないことは大切であると感じた。 また、開発の途中で「検索ボタンを押すと突然プログラムが動かなくなり、エラーが出る」という大きな問題が発生した。そこで、ブラウザに備わっている「デベロッパーツール」という開発者用の分析機能を使って、プログラムの動きや通信の内容をじっくり調べてみた。 すると、選んだチャンネルや時間帯によって送られてくるデータの形が少しずつ違っていることが分かった。この問題を解決するために、「もしデータが空っぽだったら、エラーを出さずに、そもそも機能しない」ということをプログラムの中に組み込んだ。 これにより、どんなデータが送られてきても途中で止まらない、頑丈なプログラムに修正することができた。さらに、届いた番組のタイトル、放送時間、出演者の名前などのたくさんの情報を、見ている人がひと目で理解できるようにデザインも工夫した。 JavaScriptを使って番組ごとの表示枠を自動で作り出し、見やすいレイアウトに並べて表示させる工夫をしている。 今回の開発全体を通して、エラーが出ても焦らずに「なぜ動かないのか」を論理的に考えて解決する大切さを学んだ。そして、学んだ言語を組み合わせて実際に使えるWebサイトを作り上げる楽しさと、大きな達成感を得ることができた。

数当てゲーム

今回作成したプログラムは、1から10までの整数を当てる数当てゲームである。JavaScriptのMath.random()を利用して1～10の乱数を生成し、正解となる数字を決定している。HTMLで作成したテキストボックスに予想した数字を入力し、回答ボタンを押すと、イベントハンドラによってhantei()関数が実行される。関数内では、まず予想回数を1回増やして画面に表示し、入力された値を数値として取得して予想欄へ表示する。その後、入力値と正解を比較し、正解であれば「正解です」と表示し、不正解の場合は答えが予想より大きいか小さいかのヒントを表示する。挑戦できる回数は3回までで、3回目でも正解できなかった場合は正解を表示してゲームを終了する。また、一度ゲームが終了した後に再び回答ボタンを押した場合は、ゲームが終了していることを知らせるメッセージを表示するようになっており、終了後に判定が続かないようになっている。

数当てゲームのページ: kazuate.html

各授業会の学習事項

第１回 WWW と HTML

今回学んだことは、WWWについてのこと、またWebページに使われているHTML文書の構成や要素、デバックについてだった。HTMLについては見出しを作ったり、ハイパーリンクを作ったり、画像を挿入したりと様々なことを学んだ。

演習の成果: 演習1-4: HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

今回学んだことはCSSによるWebページの装飾についてだった。CSSを使うことで前回のHTMLだけではできなかった強調表示やフォントを変えたりなど、Webページにいろいろな装飾ができるようになった。

演習の成果: 演習2-3: ウェブブラウザ説明ページの装飾

第3回 JavaScript の基本

ここまでで学んだことはWebコンテンツを作るための基礎部分である、HTML,CSS,JavaScriptの基礎を学んだ。JavaScriptはまだコンソールに文章を表示するだけのことしかできないが、webの文章や、背景などの見栄えはある程度整えられるようになった。

演習の成果: 演習3-6: オブジェクトの参照

第4回 DOM と JavaScript

ここまでで学んだことは、JavaScriptとHTMLで文字を入力できるボックスから、文字や数値を読み取り、読み取った結果を元に画面に出力する方法を学んだ。検索バーのようなものを作れるようになり、入力を受け付けられるようなプログラムを組めるようになったのでさらにwebデザインの幅が広がった。

演習の成果: 演習4-10: 足し算ページ

第5回 イベント処理

ここまでで学んだことはボタンを押すと何かを画面に映し出すJavaScriptのプログラム方法だった。ボタンを押すとすぐに画面に表示できるところまで来た。Webページとしての機能を作る最低限の力がついたと思う。

演習の成果: 演習5-7: DOMプログラミング(2)
